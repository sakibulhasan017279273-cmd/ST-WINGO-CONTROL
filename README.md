# ST Wingo Control

ST Wingo Control is a mobile-friendly WinGo control interface.

## Project Files

- `index.html` — Main interface
- `style.css` — UI and responsive design
- `script.js` — Application logic
- `assets/` — Project images/assets

## Main Features

- Secure access screen
- Live WinGo 1M data connection
- Period display
- 60-second countdown
- BIG / SMALL signal display
- Number display
- WIN / LOSS / JACKPOT result tracking
- Recent history
- Show / Hide control panel
- Login button
- Registration button
- Contact button
- Mobile responsive interface
